# Eventure Jeddah

Eventure Jeddah is a project planning and management case study developed as part of a Project Management course at the University of Jeddah.

The project focuses on planning and managing the development of an event management system from initiation to completion using project management methodologies and tools.

## Project Overview
The purpose of this project was to simulate the complete planning lifecycle of a software project, including scheduling, budgeting, scope definition, risk management, and project organization.

## Project Components
This repository includes:
- Project report
- Presentation slides
- Project planning documentation
- Scheduling and management files
- Microsoft Project files and related materials

## Topics Covered
- Project Planning
- Work Breakdown Structure (WBS)
- Scheduling and Timeline Management
- Risk Management
- Cost Estimation
- Team and Resource Planning
- Software Project Management

## Tools Used
- Microsoft Project
- Project Management Methodologies
- Documentation & Planning Techniques
